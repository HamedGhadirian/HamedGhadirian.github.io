Stylized Middle Eastern Weapons
---
A set of 14 stylized weapons with old Persian and Middle Eastern patterns. I wanted my country's culture in my work, so I designed and sketched every weapon and its patterns myself, then sculpted, textured and set them up in Unreal Engine. Pouya Abdollahi helped with the blockouts. The designs are stylized, and the materials sit between stylized and realistic.

It was sold on the Unreal Marketplace and is now available on [BlenderKit](https://www.blenderkit.com/asset-gallery?query=order:-quality+author_id:38976) and [Sketchfab](https://sketchfab.com/PhixerArt).

Every weapon has a second UV set for colour customisation. With a 16x grid mask, the second UV and material layers, buyers can change the hue and value of each part, or add an overlay colour. For example, you can recolour only the wood of the one-handed axe. It isn't an ID map, though, so parts that don't have their own UV area can't be changed separately.

-One-handed axe: 8k tris, 1 texture set
-Two-sided axe: 6k tris, 1 texture set
-Halberd: 6k tris, 1 texture set
-Shield: 5k tris, 2 texture sets (front and back)
-Sword and scabbard: 6k tris, 2 texture sets
-Dagger and scabbard: 3.5k tris, 1 texture set
-Spear: 2k tris, 1 texture set
-Bow: 9k tris, 1 texture set
-Quiver and arrow: 2k and 1k tris, 1 texture set each
-2 maces and 2 flails: 5k to 10k tris, 2 texture sets (heads and shafts)
-2 staffs: 2k to 4k tris, 1 texture set each
---
Blender, ZBrush, Substance Painter, UE5
